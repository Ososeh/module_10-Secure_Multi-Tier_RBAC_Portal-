# Module 10 – Secure Team Admin Portal

A beginner-friendly React demonstration of JWT-shaped tokens, authentication context, protected routes, role-based access, React Hook Form, Zod validation, and Axios interceptors.

**Important:** This project uses simulated authentication for learning. The token signature is not cryptographically valid and must not be used in production. Production applications need a real backend, secure token strategy, server-side authorization, and secure refresh-token handling.
